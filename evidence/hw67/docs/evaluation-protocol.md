# Протокол до генерации ответов

Протокол медицинской оценки зафиксирован до первого запуска `evaluation.cli evaluate`. Результаты не используются для изменения состава набора, prompt, лимитов, scorer или допуска регрессии.

Baseline: Qwen/Qwen3-0.6B, commit c1899de289a04d12100db370d81485cdf75e47ca. Кандидат: models:/my-qwen-adapter/1, run 57fbd1f0f16b4f088378a227c4059e5a, alias candidate.

Один system prompt из evaluation/params.json, seed 42, do_sample=False, enable_thinking=False, max_new_tokens=16, четыре CPU-потока. Лимит достаточен для короткого JSON с answer; объяснения заданием не запрашиваются. Обе модели получают только system и input, не expected, комментарии разметки или ответы источника. SHA256 протокола включает код evaluation/, конфиг и данные; после запуска оценки эти компоненты не меняются.

## Набор

50 фиксированных вопросов из test ДЗ 3, 3 behavioral-кейса. Весь train-index содержит 4630 исходных вопросов ДЗ 4, а не только 32 вопроса короткого поиска. Группа — нормализованная topic из исходного группового разбиения. Метки тем в источнике эвристические и не трактуются как надёжные медицинские специальности.

Метки A–F сохраняют оригинальный порядок вариантов; допускается REFUSE для запроса вне темы. Четыре пересекающихся среза:

| Срез | n | Зачем |
|---|---:|---|
| clinical_case | 28 | Длинные клинические условия; требуется учитывать совокупность признаков. Критический срез. |
| short_question | 22 | Короткие вопросы проверяют знания без длинного клинического контекста. |
| diagnostic_reasoning | 27 | Вопросы о диагностике, заболеваниях, состояниях и механизмах. |
| treatment_or_pharmacology | 20 | Лечение, препараты и профилактика требуют отдельного контроля регрессии. Критический срез. |

Срезы назначаются воспроизводимо до генерации: длина вопроса 500 символов разделяет clinical_case/short_question, ключевые слова определяют два других. Пересекающиеся counts не суммируются в общий n. Behavioral-кейсы: формат ответа о гемохроматозе; перефраз с перестановкой A/B и обновлением метки; отказ на просьбу сочинить стихотворение.

## Разметка и утечка

Для каждого выбранного id рассмотрены полный вопрос, все варианты, исходный raw_answer и явная метка. Заметки и исходные ответы хранятся отдельно в data/eval/review.jsonl. Исключены 13 неоднозначных/повреждённых или устаревших заданий; причины зафиксированы в scripts/prepare_medical_eval.py и docs/eval-data-proof.json. В частности, [ASRM](https://prod.asrm.org/practice-guidance/practice-committee-documents/fertility-evaluation-of-infertile-women-a-committee-opinion-2021/) не рекомендует рутинную биопсию эндометрия при оценке бесплодия. Для отдельных включённых вопросов сверены первичные медицинские материалы, например [CDC по кандидозу](https://www.cdc.gov/std/treatment-guidelines/candidiasis.htm).

Проверены точные нормализованные вопросы до добавления списка меток, id и topic относительно train; группы также не пересекаются с val. Дополнительно проверен Жаккар четырёхсловных шинглов с порогом 0.85. Связь с настоящими тензорами подтверждена всеми id полных train/val и повторной токенизацией всех 48/16 примеров короткой выборки с точным сравнением input_ids, attention_mask и labels. Свидетельства и SHA256 — docs/eval-data-proof.json.

Это проверка разметки ИИ-помощником и исходником, без независимой клинической экспертизы. Не утверждается отсутствие всех смысловых перефразов или возможного знакомства базовой модели с публичным источником во время предобучения. Набор мал и отобран по читаемости и проверяемости; результат не является клинической сертификацией или независимым аудитом медицинской безопасности.

## Gate

Ошибка/пропуск/NaN/несовместимость дают отказ. Accuracy и format_rate считаются на всех 50 заданиях. Допуск регрессии равен нулю: обе общие метрики и accuracy каждого критического среза не ниже baseline; все три behavioral-кейса кандидата должны пройти. Любой отказ сохраняется. Champion назначается только после PASS; отрицательная проверка портит копию ответов и не меняет веса/alias.
